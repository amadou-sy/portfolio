# Portfolio — Amadou Sy (One Page)

Projet React + Vite + Tailwind + Framer Motion.

## 🚀 Démarrer

```bash
npm install
npm run dev
```

## 🛠️ Build
```bash
npm run build
npm run preview
```

## 🔧 Tech
- React + Vite
- TailwindCSS
- Framer Motion

## 🌐 Déploiement rapide
- Vercel : importez le repo et déployez.
- Netlify : connectez GitHub et déployez via `npm run build` (dossier `dist`).

## 📄 Personnalisation
- Modifiez `src/App.jsx` pour changer sections & contenu.
- Ajoutez vos captures d’écran dans `public/` et liez-les.
